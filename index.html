Vista Anchors
📡
Sewio Vista Anchors
Ceiling-mounted sensors · 14 units proposed for HAL Bay 3
Mounted on the ceiling in an 8–10m grid. Receive UWB pulses from every tag and forward timing data over PoE ethernet to the RTLS server. Four or more anchors receive each tag signal simultaneously — the time difference (TDoA) is used to calculate exact XYZ position.

  • Industrial-grade — factory environments with vibration, dust, temperature

RTLS Studio
🖥️
Sewio RTLS Studio
Local positioning software · The layer ARGUS reads from
Runs on a server inside the bay LAN. Receives raw signal timing from all anchors, calculates each tag's XYZ position, and exposes it via REST/JSON API. Has its own floor map and zone management interface. For ARGUS, this is the positioning layer — our ARGUS engine sits on top and adds aircraft-specific intelligence.

  • Fully offline — LAN only, no cloud, no internet. Meets HAL air-gap requirement.
  • API: X, Y, Z coordinates + tag ID + timestamp + confidence score per tag per 100ms
  • Has built-in basic zone management — ARGUS adds aircraft-specific logic on top
  • Browser-based UI — runs in Chrome on any LAN machine
  • Live demo available at demo.sewio.net — explore it right now without buying anything
How ARGUS uses it
RTLS Studio outputs XYZ for every tag. ARGUS engine reads this stream and checks: is this tag's XY inside the Tejas fuselage polygon AND is its Z above the fuselage floor threshold? If yes — Zone 3 hard alert. RTLS Studio has no knowledge of aircraft shapes. That logic is entirely FEDS-built IP.

What We Still Need to Figure Out
Honest unknowns — some are blockers if not answered early
What does the hardware actually cost?
HID does not publish prices. Our ₹55L estimate is based on market benchmarks, not a real quote. This is the biggest unknown and affects everything. Get the quote this week.
What tag goes on very small tools — drill bits, hex keys, micro screwdrivers?
The Piccolino (smallest Sewio tag) is End of Life. Current smallest is Leonardo Asset Slim. If it's too big, the backup plan is passive RFID for tiny items — tracked at crib gate only, not inside bay. HAL asked this directly.
How do we build the 3D geofence around the Tejas?
RTLS Studio gives XYZ positions. We define: (1) a 2D polygon of the Tejas fuselage footprint, and (2) a Z height threshold for the fuselage floor. Tag inside polygon AND above Z threshold = Zone 3. We need actual Tejas dimensions — HAL may share after award.
Does UWB actually work through aircraft metal skin?
UWB (6.5–8 GHz) penetrates metal better than BLE or WiFi. Sewio specifically markets for metallic industrial environments. 4+ anchor redundancy compensates for bounce. Still needs bench testing before we commit to HAL on accuracy numbers.
What is HAL's internal work order system — SAP or custom?
Unknown. This determines how hard Phase 2 integration is. P.K. Praveen's team can tell us. Phase 1 runs standalone anyway — integration is not on the critical path.
Dashboard — Unity 3D or web app?
We proposed Unity 3D in the submission. But a web app (React / plain HTML) running on the bay's local LAN is faster to build, easier to update, and easier for HAL to maintain. Worth reconsidering before Month 1.
What is the grant disbursement timeline — when does money actually arrive?
iDEX DRISHTI grants are milestone-linked. First tranche usually comes after signing, but we need to read the award letter carefully. We may need to front some costs before first payment arrives.

Sewio RTLS Studio — Sensmap (2D Live View)
This is the interface ARGUS reads from via API · Screenshot from demo.sewio.net
This is Sewio RTLS Studio's Sensmap — the live 2D floor map showing all tags and anchors in real time. For ARGUS, we do not use this screen directly — instead, we read the position data from its API and display it on our own supervisor screen designed specifically for aircraft maintenance. But understanding what Studio shows helps us understand what data we get.

Key takeaway for ARGUS
RTLS Studio already does most of what we see here out of the box — live tag positions, zone overlays, work order linking. Our ARGUS engine adds one thing Studio cannot do: use the Z coordinate to confirm a tool is physically inside a specific 3D shape (the Tejas fuselage). That is our IP. Everything else builds on what Studio already provides via its API.
